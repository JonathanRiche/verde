# Google Play listing artwork

- `app-icon-512.png`: 512 × 512 store icon.
- `feature-graphic-1024x500.png`: opaque 1024 × 500 feature graphic.
- SVG sources retain the existing Verde logo; text is outlined from the repository's Cal Sans and Noto Sans fonts.
- `render.py` regenerates both exports with fontTools and rsvg-convert. It does not require a browser or modify source branding.

These are branding assets, not app screenshots. Add real Android screenshots using safe demo content before submitting the store listing. No private chat screenshots are included.
